# Decisions

Choices made where the spec was ambiguous or needed adapting.

| Topic                | Decision                                                                                                                                                                                                                                                       |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sample dates         | The spec's examples start 2026-11-09, but the build date was 2026-11-08. Samples cover 11-08 to 11-10 and `LAUNCH_DATE` is 2026-11-08, so it was playable immediately.                                                                                         |
| After the samples    | From 2026-11-11 the game shows "No drop today" until more puzzles are added. `validate-content` warns about upcoming gaps.                                                                                                                                     |
| `// SAMPLE DATA`     | JSON has no comments, so sample files carry `"_sample": true`.                                                                                                                                                                                                 |
| X/5 share line       | §4's text says one symbol per guess, but its example shows four symbols then ❌. The exact example wins: ❌ replaces the fifth guess's symbol.                                                                                                                 |
| Price source line    | §3.3 and §9 word this differently. The UI uses §9's required copy.                                                                                                                                                                                             |
| Clue 3 category      | `Item` has no category word, so it is derived from `categoryEmoji`. The spec's "usually costs" became "usually cost" because the words are plural ("tops", "bags").                                                                                            |
| Archive link         | The archive is Phase 2, so the no-drop screen says it is coming rather than linking to a page that doesn't exist.                                                                                                                                              |
| Midnight             | The results screen's countdown loads the new day at local midnight. A player mid-item keeps that puzzle until they reload; after that, the new day starts and the unfinished day doesn't count toward the streak. Items already finished still count in stats. |
| Corrupted storage    | Any malformed saved data resets all local progress, per §7.                                                                                                                                                                                                    |
| Extra host variables | Minority lines also get `{voted}`, `{otherVoted}`, and `{otherPct}`, so they can quote real numbers.                                                                                                                                                           |
| Names                | The game is "Cop or Drop"; the repo stays `fitle`. Host "Margot" and `copordrop.example` are config placeholders.                                                                                                                                              |
